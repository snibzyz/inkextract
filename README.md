# 🟠 INKEXTRACT

เครื่องมือจัดการนิยายแปลแบบครบวงจร — ตรวจ • คัด • รวม • แยก • คำศัพท์
ใช้งานง่ายผ่านเบราว์เซอร์

---

## ขั้นตอนติดตั้ง (ทำครั้งเดียว)

### 🔴 ขั้นที่ 1 — ติดตั้ง Python (จำเป็น)

เลือกดาวน์โหลดตามระบบของคุณ:

| ระบบ | ลิงก์ |
|------|-------|
| 🪟 Windows | [python.org/downloads/windows](https://www.python.org/downloads/windows/) |
| 🍎 macOS | [python.org/downloads/macos](https://www.python.org/downloads/macos/) |

> กด installer ตัวบนสุดในหน้านั้นได้เลย — เป็น version ล่าสุดเสมอ

🪟 **Windows**: ตอนติดตั้ง **อย่าลืมติ๊ก** `Add Python to PATH` ที่หน้าจอแรก ❗

> ถ้าเครื่องมี Python อยู่แล้ว เช็คด้วยคำสั่ง `python --version`
> (เปิด `cmd` พิมพ์ดู — ต้องเห็น `Python 3.x.x`)

### 🟠 ขั้นที่ 3 — ติดตั้งโปรแกรม

| ระบบ | ไฟล์ที่ต้องดับเบิลคลิก |
|------|----------------------|
| 🪟 Windows | `ติดตั้ง.bat` |
| 🍎 Mac | `ติดตั้ง.command` |

> โปรแกรมจะติดตั้ง package ที่จำเป็นให้อัตโนมัติ (ใช้เวลา ~1-3 นาทีครั้งแรก)
>
> 🍎 **Mac**: ถ้าขึ้นว่า "ไม่สามารถเปิดได้เพราะผู้พัฒนาไม่รู้จัก" — คลิกขวา → Open → Open

## เปิดโปรแกรม

| ระบบ | ไฟล์ที่ต้องดับเบิลคลิก |
|------|----------------------|
| 🪟 Windows | `เริ่มโปรแกรม.bat` |
| 🍎 Mac | `เริ่มโปรแกรม.command` |

เบราว์เซอร์จะเปิดขึ้นมาอัตโนมัติ — ถ้าไม่เปิดเองให้คัดลอก URL ที่ขึ้นในหน้าต่าง terminal ไปวางในเบราว์เซอร์

> 🔄 **Auto-update**: โปรแกรมจะเช็ค update จาก GitHub ทุกครั้งที่เปิด — ดาวน์โหลดและติดตั้งให้อัตโนมัติถ้ามีของใหม่ **ไม่ต้องมี Git**

## วางไฟล์ที่ไหน

ทุกอย่างอยู่ในโฟลเดอร์ **`workspace/`**

```
workspace/
├── 0-input/        ← วางไฟล์ต้นฉบับที่นี่ (.txt)
├── 1-fix/          ← ไฟล์ที่แก้ไขแล้ว (auto-fill)
├── 2-clean/        ← ไฟล์สะอาด (auto-fill)
├── 3-merge/        ← ไฟล์รวมหลายตอน (auto-fill)
├── 4-separate/     ← ไฟล์แยกตอน (auto-fill)
├── output/         ← ผลลัพธ์ต่าง ๆ
└── vocab/          ← วางไฟล์คำศัพท์ที่นี่
```

> โฟลเดอร์จะถูกสร้างให้อัตโนมัติตอนติดตั้ง

## ฟีเจอร์หลัก

| Tab | ใช้ทำอะไร |
|---|---|
| 📋 **ตรวจต้นฉบับ** | สแกนไฟล์ในโฟลเดอร์ — เน้นไฟล์ที่เล็กผิดปกติ + เรียงเลขใหม่ |
| 📖 **คำศัพท์** | จัดการ vocab — ตัดซ้ำ / หาคำขัดแย้ง / กรองความถี่ / เรียงตามต่าง ๆ |
| ✓ **ตรวจสอบและแก้ไข** | หาตัวอักษรต่างประเทศ / อังกฤษ / ตัวเลขในไฟล์แปล (มี 3 โหมด) |
| 📁 **จัดการไฟล์** | รวม / แยก / สร้าง / แปลง (TXT↔MD↔DOCX) / ตรวจรูปแบบ / ลบ |

## การตั้งค่าขั้นสูง

ไฟล์ตั้งค่าอยู่ในโฟลเดอร์ **`.config/`** (ซ่อน)

| ไฟล์ | หน้าที่ |
|---|---|
| `exclude.txt` | อักขระ/pattern ที่ไม่ต้องการให้นับเป็นข้อผิดพลาด (รองรับ regex) |

แก้ผ่าน UI ได้เลย — ที่ tab `ตรวจสอบและแก้ไข` → ขยาย "การตั้งค่ารูปแบบยกเว้น"

> 🍎 **Mac**: โฟลเดอร์ที่ขึ้นต้นด้วย `.` ถูกซ่อน — กด **Cmd+Shift+.** เพื่อแสดง

## แก้ปัญหา

| ปัญหา | แก้ยังไง |
|---|---|
| เปิดโปรแกรมแล้วไม่มีอะไรขึ้น | รอ 10-20 วินาที เบราว์เซอร์จะเปิดเอง |
| ติดตั้งแล้วเปิดไม่ได้ | ลบโฟลเดอร์ `.venv` แล้วรัน `ติดตั้ง.bat` ใหม่ |
| Mac บอกว่าเปิดไม่ได้ | คลิกขวาที่ไฟล์ `.command` → Open → Open |
| `python` ไม่เจอ | ติดตั้ง Python ใหม่ — ติ๊ก `Add Python to PATH` |
| Auto-update ไม่ทำงาน | เช็คว่าเครื่องต่ออินเทอร์เน็ตอยู่ |

- Windows 10/11 หรือ macOS 10.15+
- อินเทอร์เน็ต (ตอนติดตั้งครั้งแรก และตรวจ update)
