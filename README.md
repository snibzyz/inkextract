# 🟠 INKEXTRACT

เครื่องมือจัดการนิยายแปลแบบครบวงจร — ตรวจ • คัด • รวม • แยก • คำศัพท์ ใช้งานง่ายผ่านเบราว์เซอร์

---

## การติดตั้ง (ครั้งแรกครั้งเดียว)

### วิธีที่ 1: Clone จาก GitHub (แนะนำ — ได้ auto-update)

ต้องมี **git** ในเครื่อง — ดาวน์โหลดได้ที่ https://git-scm.com/downloads

```bash
git clone https://github.com/snibzyz/inkextract.git
cd inkextract
```

แล้วดับเบิลคลิก `ติดตั้ง.bat` (Windows) หรือ `ติดตั้ง.command` (Mac)

> ทุกครั้งที่เปิดโปรแกรม จะเช็คอัปเดตจาก GitHub ให้อัตโนมัติ ไม่ต้องอัปเดตเอง

### วิธีที่ 2: Download ZIP (ไม่มี auto-update)

โหลด ZIP จาก GitHub → แตกไฟล์ → ดับเบิลคลิก `ติดตั้ง.bat` / `ติดตั้ง.command`

### Windows
ดับเบิลคลิก **`ติดตั้ง.bat`**

> โปรแกรมจะติดตั้ง Python และส่วนประกอบให้อัตโนมัติ  
> ถ้าเครื่องไม่มี Python จะเปิดเว็บให้ดาวน์โหลดเอง

### Mac
ดับเบิลคลิก **`ติดตั้ง.command`**

> ถ้า Mac ถามว่า "ไม่สามารถเปิดได้เพราะผู้พัฒนาไม่รู้จัก"  
> ให้คลิกขวา → Open → Open

## เปิดโปรแกรม

| ระบบ | ไฟล์ที่ต้องดับเบิลคลิก |
|------|----------------------|
| Windows | `เริ่มโปรแกรม.bat` |
| Mac | `เริ่มโปรแกรม.command` |

เบราว์เซอร์จะเปิดขึ้นมาอัตโนมัติ — ถ้าไม่เปิดให้คัดลอก URL ที่ขึ้นมาแล้ววางในเบราว์เซอร์เอง

## โฟลเดอร์ workspace

วางไฟล์งานในโฟลเดอร์ **`workspace/`**

```
workspace/
├── 0-input/        ← วางไฟล์ต้นฉบับที่นี่
├── 1-fix/          ← ไฟล์ที่แก้ไขแล้ว
├── 2-clean/        ← ไฟล์สะอาด
├── 3-merge/        ← ไฟล์รวมหลายตอน
├── 4-separate/     ← ไฟล์แยกตอน
├── output/         ← ผลลัพธ์ต่างๆ
└── vocab/          ← ไฟล์คำศัพท์
```

## ฟีเจอร์

| ฟีเจอร์ | รายละเอียด |
|---------|-----------|
| ตรวจสอบคำแปล | ตรวจหาตัวอักษรต่างประเทศ / อังกฤษ / ตัวเลขที่หลงเหลือ |
| โหมด AB | ตรวจสอบไฟล์รูปแบบ `[A]` และ `[B]` |
| โหมดทั่วไป | ตรวจสอบทุกบรรทัดของไฟล์ |
| จัดการคำศัพท์ | เรียง กรอง และตรวจหาคำซ้ำใน TSV/TXT |
| รวมไฟล์ | รวมหลายตอนเป็นไฟล์เดียว |
| แยกไฟล์ | แยกไฟล์ใหญ่เป็นหลายตอน |
| แปลงไฟล์ | DOCX↔TXT↔MD |

## การตั้งค่า

ไฟล์ตั้งค่าอยู่ในโฟลเดอร์ **`.config/`** (ซ่อนอยู่)

| ไฟล์ | หน้าที่ |
|------|--------|
| `exclude.txt` | อักขระหรือ pattern ที่ไม่ต้องการให้นับเป็นข้อผิดพลาด |

แก้ไข `exclude.txt` ได้โดยตรง หรือแก้ผ่านหน้า "การตั้งค่า" ในโปรแกรม

> **Mac**: โฟลเดอร์ที่ขึ้นต้นด้วย `.` จะถูกซ่อน กด **Cmd+Shift+.** เพื่อแสดงโฟลเดอร์ซ่อน

## แก้ปัญหาเบื้องต้น

**เปิดโปรแกรมแล้วไม่มีอะไรขึ้น**  
→ รอ 10-20 วินาที เบราว์เซอร์จะเปิดเอง  

**ติดตั้งแล้วแต่ยังเปิดไม่ได้**  
→ ลองลบโฟลเดอร์ `.venv` แล้วรัน `ติดตั้ง.bat` ใหม่

**Mac บอกว่าเปิดไม่ได้**  
→ คลิกขวาที่ไฟล์ .command → Open → Open

**ต้องการ Python ใหม่กว่า**  
→ ดาวน์โหลดจาก https://www.python.org/downloads/
